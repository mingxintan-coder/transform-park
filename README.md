# 变身乐园 Transform Park

给小朋友玩的体感小游戏：电脑接电视，摄像头识别孩子的身体和动作，把孩子变成卡通角色。

**在线玩：** https://mingxintan-coder.github.io/transform-park/

## 怎么玩
1. 电脑用 HDMI 接电视，USB 摄像头放在电视上方。
2. 用 Chrome 或 Edge 打开上面的网址（需要联网）。
3. 点「📷 打开摄像头」，在下拉框里选外接摄像头（会自动记住）→ 选角色 → 选游戏 →「▶ 开始」。没有摄像头也可以点「🎬 演示」先看效果。

**找不到外接摄像头？** 插好后点 🔄；关掉微信视频、Zoom、相机等正在用摄像头的程序；页面打开后再插上的摄像头会自动切换过去。

## 游戏
- 🎭 **自由变身**：随便动，双手举高 2 秒变身；碰泡泡
- 🍎 **接水果**：用手或头接住掉下来的水果（60 秒）
- 🐹 **拍拍小动物**：小动物从身边的洞里冒出来，伸手拍拍它（60 秒）
- 🙆 **跟我做**：看小人示范的动作，跟着做（10 个动作）
- 🎵 **冻住舞会**：有音乐就跳舞，音乐停了就冻住（6 轮）
- 🎈 **找颜色**：听颜色，去摸那个颜色的气球（60 秒）

所有游戏都没有"输"：没接到、没拍到都不扣分，只会得到星星。一局结束会自动再来一局。

## 自由变身里的动作
- 🙌 双手举高 2 秒：变身下一个角色
- 🦘 跳一跳、👏 拍手、👋 挥手、✈️ 张开双臂、🍄 蹲下：各有特效和声音
- 🫧 用手或头去碰泡泡

## 隐私
画面只在本机浏览器里处理，不上传任何视频或照片。动作识别用的是 Google MediaPipe Pose。

角色均为原创形象。
