# 变身乐园 Transform Park

给小朋友玩的体感小游戏：电脑接电视，摄像头识别孩子的身体和动作，把孩子变成卡通角色。

**在线玩：** https://mingxintan-coder.github.io/transform-park/

## 怎么玩
1. 电脑用 HDMI 接电视，USB 摄像头放在电视上方。
2. 用 Chrome 或 Edge 打开上面的网址（需要联网）。
3. 点「打开摄像头」→ 选角色 →「开始玩！」。没有摄像头也可以点「演示模式」先看效果。

## 动作
- 🙌 双手举高 2 秒：变身下一个角色
- 🦘 跳一跳、👏 拍手、👋 挥手、✈️ 张开双臂、🍄 蹲下：各有特效和声音
- 🫧 用手或头去碰泡泡

## 家长遥控键
数字 1–7 换角色 · 空格 下一个 · V 真脸/卡通脸 · D 演示模式 · B 背景 · G 泡泡 · M 声音 · C 换摄像头 · P 小窗 · F 全屏 · S 设置

## 隐私
画面只在本机浏览器里处理，不上传任何视频或照片。动作识别用的是 Google MediaPipe Pose。

角色均为原创形象。
